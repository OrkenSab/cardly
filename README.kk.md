# Cardly

> **Cardly** — ресми Anki Rust өзегіне (`rslib`) тікелей негізделген, заманауи FSRS v4/v5 интервалды қайталау алгоритмдерін, толыққанды 3 панельді карточкалар шолғышын, сенсорлық басқаруға бейімделген мобильді PWA нұсқасын және AnkiDroid пен AnkiMobile үшін кірістірілген синхрондау серверін қамтитын, браузерде жұмыс істейтін Anki Desktop веб-баламасы.

## 🎯 Мүмкіндіктердің сәйкестік мәртебесі (Feature Parity)

Cardly шынайы функционалдық сәйкестік қағидатын қатаң ұстанады. Толық техникалық есеп пен тексеру парағы [docs/PARITY.md](./docs/PARITY.md) файлында берілген.

### Толық іске асырылған және тексерілген (`done`)
- **Түпнұсқа Anki өзегі**: Сервер тікелей `rslib` (Rust) ресми кітапханасымен байланысқан. Ешқандай жасанды алгоритмдер немесе JS-тегі жуықталған есептеулер жоқ.
- **Заманауи жоспарлағыш және FSRS**: Ресми Anki 23+ жоспарлағышы, FSRS v4 және FSRS v5 алгоритмдері, сондай-ақ тікелей браузер ішіндегі салмақ коэффициенттерін оңтайландыру (optimizer) және есте сақтау симуляторы.
- **Карточка мазмұны және медиа**: Құрамдас Cloze-бос орындар (`{{c1::...}}`), MathJax 3 математикалық формулалары, HTML5 аудио және видео ойнату, Web Speech API арқылы `{{tts ...}}` мәтінді дауыстап оқу, жауапты қолмен теру өрістері (`{{type:...}}` және `{{type:cloze:...}}`) және қателерді салыстырып көрсету (diff), Image Occlusion.
- **Жылдам пернелер (Shortcuts)**: Desktop Anki пернелер жинағымен толық сәйкестік: `Space`/`Enter`, `1`–`4`, `d` (Колодалар), `a` (Қосу), `b` (Шолғыш), `t` (Статистика), `y` (Синхрондау), `u` / `Ctrl+Z` (Болдырмау), тулар `1`–`7`, белгі `*`, жасыру `-`/`=`, уақытша тоқтату `@`/`!`, өшіру `Ctrl+Del`, тастау `Ctrl+Alt+N`, карта мәліметі `i`/`Ctrl+Alt+I`.
- **Карточкалар шолғышы (Browser)**: 3 панельді виртуалданған интерфейс, Anki толық іздеу синтаксисі (`deck:`, `tag:`, `is:due`, `prop:reps>5`, `flag:1`), іздеу тарихы, сақталған сұраулар, бүйір ағашы, кірістірілген редактор және жаппай әрекеттер (колоданы өзгерту, тегтерді қосу/алу, тоқтату, өшіру, іздеу және ауыстыру, көшірмелерді табу, экспорт).
- **Колода баптаулары мен карточка үлгілері**: Anki-дің ресми SvelteKit Deck Options құрамдасы; интерактивті түрде алдыңғы және артқы бетті алдын ала көруге мүмкіндік беретін толыққанды үлгілер редакторы (Card Templates).
- **Импорт және экспорт**: `.apkg`, `.colpkg` және CSV/TSV мәтіндік файлдарын сүйреп апарып (Drag-and-Drop) импорттау; `.apkg`, `.colpkg` және мәтіндік файлдарға экспорттау.
- **Кірістірілген Anki Sync Server**: Anki синхрондау протоколдарының (`/sync/*` және `/msync/*`) толық іске асуы. AnkiDroid (Android) және AnkiMobile (iOS) қосымшалары Cardly серверіңізбен тікелей синхрондалады.
- **Көппайдаланушылық оқшаулау**: Әрбір пайдаланушы үшін жеке SQLite деректер базасы мен медиа бумасы; PBKDF2 кілт генерациясы; HMAC-SHA256 HttpOnly сессиялық cookie файлдары; бөгде карточкалардағы зиянды JavaScript-тен қорғайтын `X-Cardly-Api-Token` қауіпсіздік шекарасы.
- **Мобильді PWA мүмкіндіктері**: Дербес веб-қосымша ретінде орнату (`manifest.webmanifest`, статикалық қабықты кэштейтін `sw.js` сервис-воркері, саусақпен басуға арналған 44px ірі батырмалар, safe-area шегіністері).
- **Автоматты резервтік көшірмелер**: Әрбір синхрондау мен өзгерістер алдында автоматты түрде `.colpkg` толық көшірмелерін жасау және соңғы 50 көшірмені сақтау жүйесі.

### Әдейі қосылмаған мүмкіндіктер (`skipped`)
- **Python/PyQt плагиндер менеджері**: Anki-дің десктоптық плагиндері жергілікті Python және Qt жүйесін қажет етеді; олар браузер ішіндегі қауіпсіз ортада орындала алмайды.
- **Жергілікті профиль ауыстырғыш**: Қауіпсіз көппайдаланушылық веб-аккаунт жүйесімен алмастырылды.
- **Жүйелік аудиодрайверлер (`mpv`)**: Браузердің нативті Web Audio, HTML5 медиа және Web Speech API мүмкіндіктерімен алмастырылды.

## 🚀 Бір командамен жылдам іске қосу

Cardly барлық қажетті компоненттері бар, Docker және Docker Compose арқылы оңай іске қосылатын дайын контейнер түрінде ұсынылады.

### 1. Жобаны жүктеу және конфигурациялау
```bash
git clone https://github.com/ankitects/anki.git cardly   # Немесе ағымдағы репозиторийді жүктеңіз
cd cardly
cp .env.example .env
```

`.env` файлын ашып, қолданушы деректерін көрсетіңіз:
```ini
CARDLY_USER1=alice:supersecretpassword
CARDLY_PORT=8080
```

### 2. Контейнерді іске қосу
```bash
docker compose up -d
```

### 3. Бағдарламаны қолдану
Браузерді ашып, келесі мекенжайға өтіңіз:
**`http://localhost:8080`**

`.env` файлында көрсетілген логин және құпиясөзбен жүйеге кіріңіз.

Қызметті тоқтату үшін:
```bash
docker compose down
```

## ⚙️ Баптаулар анықтамалығы (`.env`)

Cardly өз баптауларын жобаның түбірлік бумасындағы `.env` файлынан оқиды:

| Айнымалы | Әдепкі мәні | Сипаттамасы |
| :--- | :--- | :--- |
| `CARDLY_PORT` | `8080` | Веб-қосымша мен синхрондау қызметі тыңдайтын сыртқы порт. |
| `CARDLY_HOST` | `0.0.0.0` | Контейнер ішіндегі байланыстыру мекенжайы. |
| `CARDLY_DATA_DIR` | `./data` (хост) / `/data` (контейнер) | Қолданушылар базасы, медиа және сақтық көшірмелер сақталатын каталог. |
| `CARDLY_USER1` | *Міндетті* | Алғашқы қолданушының деректері (`логин:құпиясөз` форматында). |
| `CARDLY_USER2`, `CARDLY_USER3`, ... | *Қосымша* | Қосымша қолданушылар. Әр қолданушының жеке оқшауланған базасы болады. |
| `PASSWORDS_HASHED` | `0` | Егер құпиясөздер PBKDF2 PHC форматында алдын ала хэштелген болса, `1` мәнін беріңіз. |
| `CARDLY_SESSION_SECRET` | *Автоматты жасалады* | Сессиялық cookie қол қоюға арналған 256-биттік құпия кілт. Бос болса автоматты сақталады. |
| `CARDLY_COOKIE_SECURE` | `false` | Егер Cardly HTTPS (TLS) прокси артында тұрса, `true` мәніне қойыңыз. |
| `CARDLY_MAX_UPLOAD_MB` | `512` | Жүктелетін файлдардың ең жоғарғы рұқсат етілген көлемі (МБ). |
| `RUST_LOG` | `cardly_server=info,anki=info` | Сервердің журналдау деңгейлерінің сүзгісі (`tracing` синтаксисі). |

## 📱 AnkiDroid және AnkiMobile синхрондау нұсқаулығы

Cardly құрамында толыққанды кірістірілген Anki Sync Server бар. Карточкаларды, қайталау нәтижелерін және медиа файлдарды телефонмен кедергісіз үйлестіре аласыз:

### AnkiDroid (Android)
1. **AnkiDroid** &rarr; **Баптаулар** &rarr; **Синхрондау** &rarr; **Арнайы синхрондау сервері** бөлімін ашыңыз.
2. **Арнайы серверді қолдану** құсбелгісін белгілеңіз.
3. **Синхрондау серверінің сілтемесі (Sync url)**: `http://<СЕРВЕР_IP>:8080/sync/`
4. **Медиа синхрондау сілтемесі (Media sync url)**: `http://<СЕРВЕР_IP>:8080/msync/`
5. Негізгі экранға оралып, **Синхрондау** батырмасын басыңыз және `CARDLY_USER1` пайдаланушысының логині мен құпиясөзін енгізіңіз.

### AnkiMobile (iOS)
1. **AnkiMobile** &rarr; **Preferences** &rarr; **Syncing** &rarr; **Custom Server** бөліміне өтіңіз.
2. **Sync URL** өрісіне: `http://<СЕРВЕР_IP>:8080/sync/` жазыңыз.
3. Логин және құпиясөзді енгізіңіз.
4. **Sync Now** батырмасын басыңыз.

> [!TIP]
> Серверді ғаламтор немесе қоғамдық Wi-Fi желілері арқылы пайдаланған кезде Cardly-ді HTTPS кері проксиімен (мысалы, Caddy немесе Nginx) қорғап, Let's Encrypt сертификатын орнату және `CARDLY_COOKIE_SECURE=true` режимін қосу ұсынылады.

## 🛠 Жергілікті әзірлеу және құрастыру

Docker қолданбай, бағдарламаны әзірлеуші режімінде іске қосу үшін:

### Жүйелік талаптар
- **Rust** 1.80+ (`cargo`)
- **Node.js** 20+ / 22+ (`npm`)
- **SQLite3** кітапханалары және **protobuf** құрастыру пакеті

### Құрастыру және қосу
```bash
# 1. Svelte 5 веб-интерфейсін құрастыру
cd web
npm install
npm run build
cd ..

# 2. Rust серверін іске қосу
CARDLY_USER1="alice:secret123" \
```

## ❓ Жиі қойылатын сұрақтар (FAQ)

### Cardly ресми Anki өнімі ме?
Жоқ. Cardly — тәуелсіз, ашық бастапқы кодты жоба. Ол Ankitects Pty Ltd компаниясымен немесе Дэмиен Элмспен ресми байланыспаған. Жоба Anki өзегінің ашық бастапқы кодын GNU AGPLv3 лицензиясы талаптарына сай толық пайдаланады.

### Cardly қайталау аралықтарын Anki Desktop сияқты дәл есептей ме?
Иә, 100% дәл есептейді. Алгоритмдерді JavaScript тілінде жуықтап жасаған өзге веб-сайттардан айырмашылығы — Cardly ресми `rslib` (Rust) кітапханасына тікелей сүйенеді. Барлық аралықтарды есептеу, FSRS формулалары және деректер базасының жазбалары түпнұсқа Anki кодымен орындалады.

### Бұрынғы `.apkg` немесе `.colpkg` жинақтарымды жүктей аламын ба?
Иә. Кез келген `.apkg` колодасын немесе `.colpkg` толық жинағын қарапайым сүйреп апару (drag-and-drop) арқылы немесе **Файл &rarr; Импорт** мәзірі арқылы жүктей аласыз. Барлық карточкалар, тегтер, суреттер, аудио және қайталау тарихы толықтай сақталады.

### Anki десктоп плагиндерін (Add-ons) қолдай ма?
Жоқ. Anki плагиндері Python тілінде жазылған және дербес компьютердің PyQt6 графикалық интерфейсіне негізделген. Оларды браузерде немесе веб-серверде орындау қауіпсіздікке қайшы келеді. Дегенмен, плагиндер арқылы жиі орнатылатын негізгі мүмкіндіктер (FSRS, толық статистика, Image Occlusion, күңгірт реңк) Cardly ішінде бастапқыдан дайын тұр.

### Қолданушы деректері қалай қорғалған?
Әрбір тіркелгінің жеке оқшауланған SQLite базасы (`collection.anki2`), медиа каталогы және сақтық көшірмелері болады. Жүйеге кіру үшін PBKDF2 хэштеуі мен HttpOnly cookie файлдары пайдаланылады. Ал бөгде карточкалардағы JavaScript кодтары қауіпсіз `iframe` песочницасында оқшауланып, серверлік құпиялар мен сессияларға қол жеткізе алмайды.

### Автоматты резервтік көшірме қалай жұмыс істейді?
Cardly синхрондау мен маңызды әрекеттер алдында бүкіл жинақтың `.colpkg` түріндегі толық суретін `/data/users/<пайдаланушы>/backups/` каталогына автоматты түрде сақтайды. Жүйе соңғы 50 көшірмені ұстап тұрады да, ескілерін тазалап отырады. Кез келген уақытта **Баптаулар &rarr; Сақтық көшірмелер** бөлімінен көшірмені жүктеп алуға немесе қалпына келтіруге болады.
