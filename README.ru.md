# Cardly

> **Cardly** — точный, пиксель-в-пиксель веб-клон приложения Anki Desktop, работающий прямо в браузере на базе официального ядра Anki на Rust (`rslib`), с поддержкой современных алгоритмов интервального повторения FSRS v4/v5, полноценным 3-панельным браузером карточек, мобильным режимом PWA с оптимизацией под сенсорный ввод и встроенным сервером синхронизации для AnkiDroid и AnkiMobile.

## 🎯 Статус соответствия функциональности (Feature Parity)

Cardly придерживается принципа честной фиксации возможностей. Полная верификация и технический чек-лист представлены в файле [docs/PARITY.md](./docs/PARITY.md).

### Реализовано и верифицировано (`done`)
- **Оригинальное ядро Anki**: Сервер напрямую подключает библиотеку `rslib` (Rust). Никакой эмуляции или примерного переписывания алгоритмов в JS.
- **Современный планировщик и FSRS**: Полная поддержка планировщика Anki 23+, алгоритмов FSRS v4 и FSRS v5 с оптимизатором весов и симулятором удержания прямо в интерфейсе.
- **Контент карточек и медиа**: Вложенные Cloze-пропуски (`{{c1::...}}`), MathJax 3, воспроизведение аудио и HTML5 видео, синтез речи `{{tts ...}}` через Web Speech API, поля ввода ответа (`{{type:...}}` и `{{type:cloze:...}}`) с посимвольной подсветкой различий (diff), Image Occlusion.
- **Горячие клавиши Desktop Anki**: Полный набор сочетаний клавиш: `Space`/`Enter`, `1`–`4`, `d` (Колоды), `a` (Добавить), `b` (Браузер), `t` (Статистика), `y` (Синхронизация), `u` / `Ctrl+Z` (Отмена), флаги `1`–`7`, метка `*`, скрыть `-`/`=`, заморозить `@`/`!`, удалить `Ctrl+Del`, сбросить `Ctrl+Alt+N`, информация `i`/`Ctrl+Alt+I`.
- **Браузер карточек**: 3-панельный виртуализированный интерфейс с поддержкой поискового синтаксиса Anki (`deck:`, `tag:`, `is:due`, `prop:reps>5`, `flag:1`), историей поиска, сохраненными запросами, боковым деревом, встроенным редактором и массовыми операциями (смена колоды, теги, заморозка, удаление, поиск и замена, поиск дубликатов, экспорт).
- **Настройки колод и шаблоны**: Переиспользование официального SvelteKit-модуля Deck Options; полноценный редактор шаблонов карточек с интерактивным просмотром HTML/CSS для лицевой и обратной сторон.
- **Импорт и экспорт**: Перетаскивание файлов (Drag-and-Drop) `.apkg`, `.colpkg`, CSV/TSV; экспорт в `.apkg`, `.colpkg` и текстовые форматы.
- **Встроенный сервер синхронизации Anki Sync Server**: Полная реализация протоколов `/sync/*` и `/msync/*`, позволяющая приложениям AnkiDroid (Android) и AnkiMobile (iOS) синхронизироваться напрямую с вашим сервером Cardly.
- **Многопользовательская изоляция**: Полностью изолированные базы SQLite и папки медиа для каждого пользователя; хеширование паролей PBKDF2; безопасные сессионные куки HMAC-SHA256 HttpOnly; токен `X-Cardly-Api-Token` для защиты от вредоносного JS внутри карточек.
- **Адаптивный мобильный PWA-режим**: Установка в качестве автономного веб-приложения (манифест `manifest.webmanifest`, сервис-воркер `sw.js` для кеширования оболочки, безопасные отступы safe-area, крупные тач-кнопки 44px).
- **Автоматические резервные копии**: Автоматическое создание полных снимков `.colpkg` перед синхронизацией и изменениями с автоматической ротацией (сохраняются последние 50 версий).

### Осознанно исключено из веб-версии (`skipped`)
- **Менеджер дополнений Python/PyQt**: Десктопные плагины Anki требуют локального интерпретатора Python и Qt-библиотек; они не могут безопасно исполняться в веб-песочнице.
- **Переключатель профилей**: Заменен классической веб-аутентификацией с изолированными учетными записями.
- **Системные аудиодрайверы (`mpv`)**: Заменены нативными возможностями Web Audio, HTML5-плеерами и Web Speech API.

## ✨ Генератор карточек с ИИ (AI Card Generator)

Cardly оснащен встроенным генератором карточек на базе искусственного интеллекта, который преобразует конспекты, статьи и фотографии учебников в атомарные карточки для интервального повторения по алгоритму **FSRS**:

- **Мультимодальный ввод**: Вставляйте исходный текст либо загружайте фотографии книжных страниц, схем и рукописных заметок для распознавания текста (OCR).
- **Форматы карточек**: Создание атомарных карточек **Вопрос-Ответ (Basic)** или карточек с пропусками **Cloze (`{{c1::...}}`)**.
- **Выбор провайдера ИИ**:
  - **Google Gemini** (`gemini-1.5-flash`, `gemini-1.5-pro` через Google AI Studio).
  - **OpenAI и OpenRouter** (`gpt-4o-mini`, `deepseek-chat`).
  - **Локальная Ollama** (`llama3.2`, `mistral`, `llava`) для 100% приватной работы без подключения к интернету.
- **Предпросмотр и массовое добавление**: Интерактивное редактирование сгенерированных карточек, настройка тегов и добавление в выбранную колоду в один клик.

Горячая клавиша: **`Ctrl+Shift+G`** или кнопка **✨ AI** на верхней панели. Подробная инструкция в файле [docs/AI_GENERATOR.md](./docs/AI_GENERATOR.md).

## 🚀 Быстрый запуск одной командой

Cardly упакован в оптимизированный контейнер, готовый к развертыванию через Docker и Docker Compose.

### 1. Клонирование и настройка
```bash
git clone https://github.com/ankitects/anki.git cardly   # Или клонируйте текущий репозиторий
cd cardly
cp .env.example .env
```

Отредактируйте файл `.env`, указав учетные записи пользователей:
```ini
CARDLY_USER1=alice:supersecretpassword
CARDLY_PORT=8080
```

### 2. Запуск контейнера
```bash
docker compose up -d
```

### 3. Начало работы
Откройте браузер и перейдите по адресу:
**`http://localhost:8080`**

Авторизуйтесь с логином и паролем, заданными в `.env`.

Для остановки контейнера:
```bash
docker compose down
```

## ⚙️ Справочник конфигурации (`.env`)

Cardly считывает переменные окружения из файла `.env` в корне проекта:

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `CARDLY_PORT` | `8080` | Порт хоста, на котором принимаются HTTP-запросы и запросы синхронизации. |
| `CARDLY_HOST` | `0.0.0.0` | Сетевой адрес для привязки сокета внутри контейнера. |
| `CARDLY_DATA_DIR` | `./data` (хост) / `/data` (контейнер) | Каталог постоянного хранилища (коллекции, медиа, резервные копии). |
| `CARDLY_USER1` | *Обязательно* | Первый пользователь в формате `username:password`. |
| `CARDLY_USER2`, `CARDLY_USER3`, ... | *Опционально* | Дополнительные пользователи. Каждый получает изолированную коллекцию. |
| `PASSWORDS_HASHED` | `0` | Установите `1`, если пароли в `CARDLY_USER*` уже захэшированы в PBKDF2 PHC. |
| `CARDLY_SESSION_SECRET` | *Генерируется автоматически* | 256-битный ключ подписи сессионных cookie. Сохраняется в `$CARDLY_DATA_DIR/.session_secret`. |
| `CARDLY_COOKIE_SECURE` | `false` | Установите в `true`, если Cardly работает за обратным прокси с HTTPS (TLS). |
| `CARDLY_MAX_UPLOAD_MB` | `512` | Максимальный размер загружаемых файлов (.apkg, .colpkg, медиа) в МБ. |
| `RUST_LOG` | `cardly_server=info,anki=info` | Фильтр уровней логирования Rust-сервера (библиотека `tracing`). |

## 📱 Настройка синхронизации с AnkiDroid и AnkiMobile

Cardly включает полноценный встроенный сервер синхронизации Anki Sync Server. Вы можете напрямую синхронизировать колоды, прогресс повторений и медиафайлы:

### AnkiDroid (Android)
1. Откройте **AnkiDroid** &rarr; **Настройки** &rarr; **Синхронизация** &rarr; **Пользовательский сервер синхронизации**.
2. Отметьте флажок **Использовать собственный сервер**.
3. В поле **URL сервера синхронизации** введите: `http://<IP_СЕРВЕРА>:8080/sync/`
4. В поле **URL синхронизации медиа** введите: `http://<IP_СЕРВЕРА>:8080/msync/`
5. Вернитесь на главный экран, нажмите кнопку **Синхронизировать** и введите учетные данные пользователя `CARDLY_USER1`.

### AnkiMobile (iOS)
1. Откройте **AnkiMobile** &rarr; **Preferences** &rarr; **Syncing** &rarr; **Custom Server**.
2. В поле **Sync URL** укажите: `http://<IP_СЕРВЕРА>:8080/sync/`
3. Введите логин и пароль.
4. Нажмите **Sync Now**.

> [!TIP]
> При выходе в интернет или использовании общедоступного Wi-Fi рекомендуется разместить Cardly за реверс-прокси с поддержкой HTTPS (например, Caddy или Nginx) с сертификатами Let's Encrypt и установить переменную `CARDLY_COOKIE_SECURE=true`.

## 🛠 Локальная разработка и сборка

Для запуска Cardly в окружении разработчика без Docker:

### Системные требования
- **Rust** 1.80+ (`cargo`)
- **Node.js** 20+ / 22+ (`npm`)
- Библиотеки **SQLite3** и компилятор **protobuf**

### Сборка и запуск
```bash
# 1. Сборка фронтенд-оболочки (Svelte 5)
cd web
npm install
npm run build
cd ..

# 2. Запуск Rust-сервера
CARDLY_USER1="alice:secret123" \
CARDLY_PORT=8080 \
CARDLY_SHELL_DIR="./web/dist" \
CARDLY_UPSTREAM_WEB_DIR="./anki-upstream/out/qt/_aqt/data/web" \
cargo run --manifest-path server/Cargo.toml
```

### Запуск тестов
```bash
# 1. Интеграционные тесты Rust бэкенда (проверка Protobuf RPC и синхронизации)
cargo test --manifest-path server/Cargo.toml --test integration

# 2. Проверка типов Svelte 5 компонентов
npm --prefix web run check

# 3. Сквозные Playwright E2E тесты (десктопные и мобильные сценарии)
npm --prefix e2e run test
```

## ❓ Часто задаваемые вопросы (FAQ)

### Является ли Cardly официальным продуктом Anki?
Нет. Cardly — независимый проект с открытым исходным кодом. Он не аффилирован с компанией Ankitects Pty Ltd и Дэмиеном Элмсом. Проект задействует открытый исходный код ядра Anki в соответствии с условиями лицензии GNU AGPLv3.

### Вычисляет ли Cardly интервалы так же, как Anki Desktop?
Да, абсолютно идентично. В отличие от других веб-решений, пытающихся приблизительно эмулировать планировщик на JS, Cardly напрямую слинкован с официальной библиотекой Anki `rslib` на языке Rust. Все расчеты интервалов, алгоритмы FSRS и транзакции базы данных выполняет оригинальный код Anki.

### Можно ли импортировать существующие коллекции `.apkg` или `.colpkg`?
Да. Вы можете загрузить любую колоду `.apkg` или архив коллекции `.colpkg` простым перетаскиванием файлов или через меню **Файл &rarr; Импорт**. Все заметки, типы записей, теги, история повторений и медиафайлы переносятся в полном объеме.

### Поддерживаются ли дополнения (Add-ons) для Anki?
Нет. Десктопные дополнения Anki написаны на Python и вызывают низкоуровневые API графической библиотеки PyQt6. Их выполнение в веб-браузере невозможно и небезопасно. Однако функции, ради которых чаще всего ставят плагины (алгоритм FSRS, подробная статистика, скрытие областей на изображениях Image Occlusion, темная тема), уже интегрированы в Cardly изначально.

### Как защищены пользовательские данные?
Каждый аккаунт имеет полностью изолированную директорию с персональной базой данных SQLite (`collection.anki2`), медиатекой и резервными копиями. Для авторизации используются хэши PBKDF2 и куки HttpOnly. Встроенный JavaScript из сторонних колод изолирован в песочницах `iframe` без доступа к сессиям и API сервера.

### Как работают резервные копии?
Cardly автоматически делает снимки всей коллекции в формате `.colpkg` перед синхронизацией и критическими операциями. Файлы бэкапов сохраняются в томе данных `/data/users/<username>/backups/`. Система автоматически оставляет 50 самых свежих снимков. Вы можете скачать или восстановить резервную копию в любой момент через раздел **Настройки &rarr; Резервные копии**.
