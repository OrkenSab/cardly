CORE CAPABILITIES

Engineered with Zero Compromises

Cardly does not rewrite or approximate Anki's algorithms. It links directly against upstream Rust binaries and reusable Svelte components.

Official Anki Core (rslib)

Directly links the official Rust core. Every schedule calculation, database schema mutation, and SQLite transaction is executed by upstream Anki code.

FSRS v4 / v5 Scheduler

Full support for the modern Free Spaced Repetition Scheduler with live in-browser weight optimization and future retention simulation.

MathJax 3, Cloze & Audio

Client-side MathJax formulas, nested cloze deletions, typed answer character diffing, HTML5 audio, video, and Web Speech API text-to-speech.

3-Pane Virtualized Browser

Desktop-grade card browser with full search syntax (deck:, tag:, is:due), sortable columns, and bulk batch actions.

Mobile PWA & Touch Controls

Installable on iPhone and Android with standalone display, service worker offline shell, safe area insets, and ergonomic 44px touch rating buttons.

Built-in Sync Server

Full implementation of Anki's sync protocol (/sync/* and /msync/*). AnkiDroid and AnkiMobile sync directly with your self-hosted server.

Got Questions? We Have Answers

No. Cardly is an independent, open-source project. It is not affiliated with, sponsored by, or endorsed by Damien Elmes or Ankitects Pty Ltd. It links directly against the open-source Rust libraries of Anki in full compliance with GNU AGPL-3.0.

Cardly directly invokes Anki's official Rust core (rslib) rather than approximating spaced repetition math in JavaScript. Every interval, FSRS power formula, and scheduling state transition runs through upstream Anki code.

Cardly is completely free and open-source software. You can host it on any cheap cloud VPS ($4–$5/month on Hetzner, DigitalOcean, Linode), deploy it on a home Raspberry Pi, or run it on modern serverless containers (Fly.io, Railway) within their free/hobby tiers.

Cardly embeds Anki's official HTTP sync server protocol. In AnkiDroid or AnkiMobile settings, simply enable "Custom Sync Server" and point it to your Cardly instance URL (http://<IP>:8080/sync/). Your collections and media sync automatically!
